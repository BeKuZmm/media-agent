# 🤖 Media Agent Bot

AI asosida ishlaydigan media menejeri bot.

## Imkoniyatlar
- ✍️ Kontent yozish (Instagram + Telegram)
- 📰 Yangiliklar qidirib post tayyorlash
- 🌍 Ko'p tilli tarjima
- 📅 Post rejalashtirish
- 🖼 Rasm tahlil qilish
- 📤 Avtomatik posting

## Sozlash

### 1. Environment Variables (Render.com da)
```
ANTHROPIC_API_KEY=your_key
TELEGRAM_BOT_TOKEN=your_token
TELEGRAM_CHANNEL_ID=@your_channel
INSTAGRAM_USERNAME=your_username
INSTAGRAM_PASSWORD=your_password
PEXELS_API_KEY=your_key (ixtiyoriy)
UNSPLASH_ACCESS_KEY=your_key (ixtiyoriy)
```

### 2. Rasm API lari (bepul)
- **Pexels**: https://www.pexels.com/api/
- **Unsplash**: https://unsplash.com/developers

### 3. Deploy (Render.com)
1. GitHub ga yuklang
2. Render.com → New → Background Worker
3. GitHub reponi ulang
4. Environment Variables qo'shing
5. Deploy tugmasi
